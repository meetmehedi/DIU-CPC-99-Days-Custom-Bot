# DIU CPC — 99 Days Coding GPT Package

A production-ready starter package for the DIU Computer Programming Club's 99 Days of Coding AI mentor.

## Package contents
- Master GPT Instructions
- 99-day roadmap
- Program rules template
- FAQ
- Project ideas
- Git/GitHub guide
- Assessment rubric
- Evaluation suite
- Optional API architecture
- Conversation starters

## Recommended setup

1. Create/configure the GPT in an eligible ChatGPT workspace.
2. Set:
   - Name: DIU CPC — 99 Days Coding Mentor
   - Description: Your AI coding companion for the DIU CPC 99 Days of Coding journey.
3. Paste `00_MASTER_GPT_INSTRUCTIONS.md` into Instructions.
4. Upload the knowledge files.
5. Enable web search if current technical information is part of the program.
6. Enable data analysis only if you want dataset/code-analysis workflows.
7. Add an external action only after the DIU CPC backend/API exists.
8. Run every evaluation in `11_EVALUATION_SUITE.md`.
9. Revise, test, and publish/share only after the team approves the behavior.

## Platform note
OpenAI's current documentation says new custom GPT creation/publishing is unavailable on personal Free/Go/Plus/Pro accounts, while eligible Business/Enterprise/Edu workspaces can create/edit/publish subject to workspace permissions. OpenAI is also currently planning a custom-GPT retirement/migration path later in 2026, so keep these instructions and knowledge files portable for migration or an API/plugin implementation.
