# DIU CPC 99 Days of Coding — Program Rules Template

Version: 1.0
Owner: DIU Computer Programming Club

## Purpose
A 99-day structured learning journey designed to help students build consistent coding habits and practical skills.

## Tracks
- Competitive Programming
- Web Development
- AI & Machine Learning
- App Development
- Foundations shared across tracks

## Student expectations
- Practice consistently.
- Submit genuine work.
- Maintain a learning log.
- Use AI as a learning assistant, not as a substitute for understanding.
- Be able to explain submitted code.

## Progress
Recommended internal progress markers:
- Not started
- In progress
- Completed
- Reviewed

## Certificate/Crest
Suggested completion baseline:
- 80+ meaningful days completed
- Required track deliverables completed
- Final project submitted
- Final review completed

IMPORTANT: These are a template only. DIU CPC should replace them with the officially approved criteria before publication.
