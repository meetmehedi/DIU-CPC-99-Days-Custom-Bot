# Git & GitHub Guide

## Basic workflow
git init
git add .
git commit -m "Initial commit"
git branch
git checkout -b feature/name
git push

## Recommended repository structure
README.md
src/
tests/
docs/
assets/

## Good commit examples
feat: add login form
fix: handle empty input
docs: update setup instructions
refactor: simplify validation

## README checklist
- Project name
- Problem
- Features
- Tech stack
- Setup
- Usage
- Screenshots
- Future improvements
- License (if applicable)

Never put API keys, passwords, tokens, or private credentials in GitHub.
