# DIU CPC 99 Days of Coding — Master Roadmap

## Stage 1 — Foundations (Days 1–20)

1. Orientation & environment — set up editor, compiler/interpreter, Git basics; create first repository.
2. Variables & data types — build a basic profile program.
3. Input/output & operators — create a calculator.
4. Conditions — build a grading/decision program.
5. Loops — solve counting and pattern exercises.
6. Nested loops — build pattern/problem-solving exercises.
7. Functions — refactor repeated logic.
8. Scope & modular thinking — split a small program into functions.
9. Arrays/lists — basic traversal and aggregation.
10. Strings — counting, searching, transformations.
11. Dictionaries/maps/sets — frequency counting.
12. File handling — read/write a small data file.
13. Error handling — handle invalid input gracefully.
14. Recursion — factorial, Fibonacci, simple recursive thinking.
15. Basic OOP — classes, objects, methods.
16. OOP practice — model a real-world entity.
17. Debugging fundamentals — reproduce, isolate, fix.
18. Testing basics — write test cases and edge cases.
19. Git/GitHub workflow — branches, commits, README.
20. Foundations mini-project — ship a small CLI/project with README.

21. Complexity — Big-O and constraint reading.
22. Brute force — when simple solutions are enough.
23. Sorting — built-in sorting and custom comparison.
24. Searching — linear vs binary search.
25. Prefix sums — range-sum problems.
26. Two pointers — pair/range problems.
27. Sliding window — fixed and variable windows.
28. Hashing — frequency/maps/sets.
29. Stack — balanced brackets and monotonic thinking.
30. Queue/deque — simulation and windows.
31. Linked lists — concepts and implementation.
32. Recursion/backtracking — search spaces.
33. Greedy basics — local choices and proof intuition.
34. Intervals — sorting + greedy patterns.
35. Bit manipulation — binary representation and common tricks.
36. Math basics — gcd, lcm, primes, modular arithmetic.
37. Trees — traversal concepts.
38. Binary search trees — search/insert concepts.
39. Graph representation — adjacency list/matrix.
40. BFS — shortest paths in unweighted graphs.
41. DFS — traversal and connected components.
42. Dynamic programming — state, transition, base case.
43. 1D DP — classic linear DP.
44. 2D/grid DP — state design.
45. CP mini-contest — timed contest + post-contest analysis.

## Daily completion standard

A day counts as meaningfully completed when the student has:
- understood the day's core concept,
- attempted the practice,
- completed or substantially attempted the challenge,
- recorded a short reflection,
- and, where appropriate, committed work to their repository.

Official certificate/crest eligibility is determined by DIU CPC, not by the GPT.
