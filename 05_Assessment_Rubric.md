# 99 Days Assessment Rubric

Score each area 1–5.

1. Consistency
2. Problem-solving
3. Code correctness
4. Code quality
5. Complexity awareness
6. Git/GitHub practice
7. Project execution
8. Documentation
9. Testing/debugging
10. Ability to explain own work

Suggested interpretation:
45–50: Excellent
35–44: Strong
25–34: Developing
10–24: Needs more guided practice

This rubric is advisory until approved by DIU CPC.
